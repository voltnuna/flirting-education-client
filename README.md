```

  - 📂 assets
    - 📂 fonts
    - 📂 images
    - 📂 scss
    - 📂 ts
- 📂 components
- 📂 layouts
- 📂 pages
- 📂 typings
- 📂 utils
- 📂 hooks

- ✅📄 tsconfig.json : js설정파일 (추가할 경로가 있을 경우 이 파일에서 셋팅한다.)
```
